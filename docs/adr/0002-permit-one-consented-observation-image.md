# Permit one consented Observation Image for visual interpretation

The planned `localDemo` keeps all pixels, comments, and audio on-device and compiles no remote path. A separate `visualDemo` may transmit exactly one reduced, metadata-free Observation Image—shown frozen to the photographer—only after per-Complaint Visual Coaching Consent, and only to disambiguate whole-frame color cast or one-face size/perspective meaning. The remote service returns a fixed family-limited Visual Hint and never owns wording, diagnosis, capability checks, planning, camera control, or verification. The feature is absent unless provider/privacy, inline-image API, quota, safety, usefulness, and participant-readiness gates pass.

This supersedes ADR 0001 because `visualDemo` intentionally abandons the absolute promise that no preview or captured-photo pixels ever leave the phone. It preserves no streaming, no audio/EXIF/URI/landmarks/tracking/hardware ID, no remembered consent, and the fully local fallback. The trade is a narrower privacy promise and a larger consent/security/evaluation burden for visual disambiguation that must beat the local clarification baseline; failure means deleting the hosted path rather than adding providers or storage.
