# Call Bailian Qwen directly from the private demo app

The single-device demo calls Qwen3.7 Flash through Alibaba Cloud Model Studio in China (Beijing) with a disposable operator-entered key. It sends only one reduced Observation Image for an eligible complaint, accepts only the fixed Visual Hint schema, and keeps planning, camera control, and verification local. Direct credentials and provider retention remain unsuitable for a distributed production app, which should use a backend proxy. This supersedes ADR 0003.
